## 二、⚠️ 安装前必读：这个包无法覆盖安装

**本次构建用的是新生成的 `development.keystore`，与历史发布版本不是同一个密钥。**

原因：`build-local.ps1` 默认 `-Work` 指向工作区外的 `D:\work`，在文件沙箱下被拒绝；
为完成构建，本次把 `-Work` 改到了工作区内的 `.buildwork`，因此**该目录下没有原有密钥，
脚本自动新建了一个**。

**后果**：
- 若手机上装的是用**旧密钥**签名的历史版本（1.0.1 及之前），安装 `y7c_0.1` 会报
  `INSTALL_FAILED_UPDATE_INCOMPATIBLE`（签名不一致）。
- 此时**必须先卸载旧应用**，但卸载会**清除本地数据**：已保存的课表缓存、成绩、
  自定义课程、背景图片、加密登录凭证**都会丢失**。

**建议**：若要用这台手机验证，先确认可以接受数据丢失，或把原有
`development.keystore` 放到 `.buildwork\` 后重新构建（那样才能覆盖安装）。

> 检查手机上已装版本与签名：
> ```powershell
> adb shell dumpsys package cn.jhun.sanjiaohu | Select-String versionName
> ```

## 四、本次验证的重点：阶段 1 重构是否造成视觉回归

本次改动**只搬移了 7 个 UI 工具方法**（`dp`/`shape`/`column`/`row`/`space`/`place`/`weighted`），
理论上视觉应完全不变。但**测试覆盖不到像素**，因此必须靠肉眼确认以下几处——
**它们是唯一可能出现差异的地方**（都依赖 `dp()` 或 `shape()`）：

### 4.1 间距与尺寸（`dp()` 相关）

| 检查点 | 期望 |
|---|---|
| 首页四个入口卡片的**间距**是否均匀 | 与旧版一致，无错位/重叠 |
| 课表**七天十二节网格**是否完整一屏 | 无溢出、无截断、时间栏文字可读 |
| 底部导航三个栏目的**高度与对齐** | 图标+文字居中，无偏移 |
| 各页面顶部标题与内容**留白** | 与旧版一致 |

### 4.2 圆角与背景（`shape()` 相关）——**重点**

| 检查点 | 期望 | 风险 |
|---|---|---|
| **登录页**账号/密码输入框圆角 | **圆角**，不是直角 | ⚠️ 见下方说明 |
| **登录页**「登 录」按钮圆角 | **圆角** | ⚠️ 见下方说明 |
| 底部弹出面板圆角 | 大圆角（28dp 观感） | |
| 课程卡片圆角 | 小圆角（6dp 观感） | |
| 首页入口卡片圆角 | 大圆角（20dp 观感） | |
| 关于页赞助码白底圆角 | 圆角（18dp） | |

> **为什么登录页是重点**：`LoginActivity` 原本有**独有的单参数** `shape(color)`，
> 圆角**硬编码 16**；而其他类都是 `shape(color, radius)`。合并时若处理不当，
> 登录页的圆角会**静默变成 0（直角）**——编译不报错、测试也测不出。
> 本次已显式保留为 `Ui.shape(this,color,16)`，但**必须肉眼确认**。

### 4.3 版本号显示

- 进入「个人」页 → 右上角「关于」→ 应显示版本号。
- **预期显示 `vy7c_0.1`** ⚠️ 见下方说明。

> **关于版本号的已知问题**：`AboutActivity` 的逻辑是
> "若版本名不以 `v` 开头则自动补一个 `v`"。因新版本号是 `y7c_0.1`（不以 v 开头），
> 界面会显示成 **`vy7c_0.1`**，看起来像多了一个 v。
> **这是既有逻辑与新版本号命名的交互结果，不是本次重构引入的缺陷。**
> 若希望显示为 `y7c_0.1`，需要改 `AboutActivity` 第 40 行的补前缀逻辑——请确认。
